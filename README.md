# BLC-C6-Project: DATA ANALYSIS AND MACHINE LEARNING

## Overview
A data analytics project that analyzes business listings, ratings, review counts, locations, and categories to identify patterns and assign category-level priorities.

## Key Features
- Data cleaning and exploratory data analysis (EDA).
- Business distribution by country, city, and category.
- Rating and review performance analysis.
- High, Medium, and Low category-level priority classification.
- Machine learning-based priority prediction.
- Interactive dashboard for visualizing business insights.

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook, Power BI, Tableau and Excel.

## Workflow
Data Cleaning → EDA → Review Scoring → Priority Classification → Machine Learning → Dashboard & Final Report.

## Outcome
Transforms raw business data into actionable insights through data analysis, classification, and visualization.
